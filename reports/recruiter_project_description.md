# MarketLens Recruiter Project Description

## Short Description

MarketLens is a financial market intelligence dashboard that collects market and macroeconomic data from APIs, cleans and analyzes the data in Python, visualizes the results in Streamlit, and includes an LLM-ready market summary workflow with fallback mode.

## One-Paragraph Recruiter Summary

I built MarketLens, a financial data intelligence dashboard that demonstrates an end-to-end data workflow. It uses Python scripts to collect SPY market data and DGS10 macroeconomic data from APIs, cleans and merges the data, engineers financial features such as returns, moving averages, RSI, volatility, and drawdown, and presents the results in an interactive Streamlit dashboard. I also added GitHub Actions automation for data refresh and an LLM-ready market summary page with safe fallback behavior.
