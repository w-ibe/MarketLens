# MarketLens

MarketLens is a financial market intelligence dashboard.

It collects market and macroeconomic data from APIs, cleans and merges the data in Python, calculates financial indicators, visualizes results in a Streamlit dashboard, and includes an optional LLM-powered summary feature.

## Skills Demonstrated

- API-based data collection
- Python data cleaning and merging
- Financial data analysis
- Feature engineering
- Interactive dashboard development
- Data visualization
- Optional LLM-powered summary generation
- Workflow automation with GitHub Actions
- Simple project website with GitHub Pages

## Tech Stack

- Python
- pandas
- NumPy
- matplotlib
- Plotly
- yfinance
- FRED API
- Streamlit
- scikit-learn
- OpenAI API
- GitHub Actions
- GitHub Pages
